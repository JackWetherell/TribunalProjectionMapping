# Scroll

A TouchDesigner project that layers real-time VFX over a scanned scroll print of the Tribunal (Morrowind),
for projection mapping onto a large physical print of the same artwork.

## Requirements

- [TouchDesigner](https://derivative.ca/download) 2023.11225 or later
- A projector for the mapped output (not needed to open or edit the project)

## Files

| Path | Purpose |
| --- | --- |
| `scroll.toe` | Main TouchDesigner project |
| `scroll.png` | Source artwork (1066 x 1475) |
| `Backup/` | TouchDesigner auto-backups |
